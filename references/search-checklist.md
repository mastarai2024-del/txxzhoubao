# 检索检查表

先从上期计划、当前项目和本人身份提取主题，使用真实实体名称补搜。不要预设固定公司、同事、业务方向或已经完成的事项。

- 文档：项目名、功能名、需求、方案、评审、验收；同时看创建/更新时间与编辑者。
- 群聊：用 sender、@me、chat、thread 和 start/end 限定范围。自然语言需求拆成筛选条件，query 只用真实关键词。
- 会议：已知会议标题、评审、拉通、复盘、专项讨论；结合本人参会与行动项。
- 项目：先枚举本人关联需求和缺陷，再查本期创建、变更或操作记录，不把全部历史条目当本周工作。
- 日历：查本期范围内会议，为前面未覆盖事项提供线索；不凭邀请推定参加。

一次补一个尚缺证据的主题；记录范围、分页终点和来源状态。发现新项目线索时追溯原对象，跨来源归并。待审批或缺权限不反复申请，不切换身份绕过。
